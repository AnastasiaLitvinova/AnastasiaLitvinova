## 🔥 Текущие проекты

### 1. [Классификация изображений CIFAR-10](https://github.com/AnastasiaLitvinova/VisionForge)

- Модель на основе **ResNet18 с SE-блоками**
- **Optuna** для подбора гиперпараметров
- Точность **92%** с аугментацией данных
- Демо-интерфейс на **Streamlit**

### 2. [Детекция огня и дыма (в разработке)](https://github.com/AnastasiaLitvinova/SmokeDetection)

- Исследую подходы:
  - **YOLOv8** для object detection
  - Ансамбли с **CNN-классификаторами** (EfficientNet)
  - Оптимизация **precision/recall** для уменьшения false positives
- Работа с датасетами:
  - [Fire Detection Dataset](https://www.kaggle.com/datasets/phylake1337/fire-dataset)
  - [Smoke Detection Dataset](https://www.kaggle.com/datasets/deepcontractor/smoke-detection-dataset)
